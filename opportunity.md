## The Opportunity

I'm building **Asimi** — an open-source, multi-model AI coding agent. It's built in Go, vi-based, and already works with any OpenAI-compatible API. Think of it as a developer's terminal tool that uses AI to write, test, and review code — but with a unique twist:

**Asimi's architecture is modelled on imperial China's court system (三省六部).** A developer is the ruler. AI agents act as ministers — the Forge writes code, the Judge runs tests, the Sage reviews quality. No single agent ships code alone. This separation of powers solves the biggest problem in AI coding: models being too eager to please.

The cultural design isn't cosmetic. When a frontier model sees kanji like 工部 or 刑部 in its system prompt, its classical training activates. Chinese models don't just *work* in Asimi — they have a cultural home advantage. This is something no Western coding agent can offer.

You can read the full story here: https://asimi.dev/blog/giving-a-harness-purpose
